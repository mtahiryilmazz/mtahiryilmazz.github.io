# mtahiryilmazz.github.io

M. Tahir Yılmaz — Kişisel Portfolyo & Sistem Çözümleri Web Sitesi.

Tasarım felsefesi: **tasteskill**, **impeccable**, **GSAP** ve **Three.js** kullanılarak; yapay zeka jeneriklerinden uzak, gerçek sistem mühendisliği ve otomasyon projelerini ön plana çıkaran modern bir bento grid ve interaktif terminal arayüzü.

## 🚀 Öne Çıkan Özellikler

- **Ödüllü Tipografi & Renk Paleti:** Space Grotesk, Inter ve JetBrains Mono ile Deep Obsidian endüstriyel koyu tema.
- **Hafif 3D Çekirdek:** WebGL / Three.js ile pil ve GPU dostu dinamik sistem ağ düğümleri (constellation). Sekme pasifleştiğinde otomatik uyku modu.
- **GSAP Mikro-Animasyonları:** Akıcı girişler, kart manyetiği ve kaydırma tetikleyicileri (ScrollTrigger).
- **İnteraktif CLI Terminali:** Ziyaretçilerin doğrudan tarayıcı üzerinden `yapair`, `pwxe`, `oxidesk` ve `winraze` gibi araçları simüle edebileceği gerçekçi terminal bileşeni.
- **Sıfır Bağımlılık / Zero-Build:** Node modül derlemesi gerektirmez, doğrudan GitHub Pages üzerinde çalışır.

## 📦 Projeler Vitrini

- **yapair:** AI-powered Windows diagnostics, repair and verification agent (C# .NET)
- **OxiDesk:** Windows Fluent IT Uzak Masaüstü ve Cihaz Yönetim Ekosistemi (Rust)
- **pwxe & PwX-Studio:** PowerShell to standalone EXE build engine & Windows GUI application
- **winraze:** Ultra-fast Windows deep cleanup & memory optimizer (Rust)
- **SysForge-Studio:** Kurumsal BT & sistem operasyon paketi (Python)

## 🌐 GitHub Pages'e Dağıtım (1 Dakika)

1. GitHub'da `mtahiryilmazz.github.io` adında yeni bir public depo oluşturun (zaten yoksa).
2. Bu klasördeki dosyaları depoya push edin:
   ```bash
   git init
   git add .
   git commit -m "feat: modern redesigned portfolio with Three.js, GSAP and Taste aesthetics"
   git branch -M main
   git remote add origin https://github.com/mtahiryilmazz/mtahiryilmazz.github.io.git
   git push -u origin main
   ```
3. GitHub Depo Ayarları -> **Pages** -> Source: **Deploy from a branch (main / root)** seçeneğini aktif edin.
4. Siteniz anında `https://mtahiryilmazz.github.io` adresinde canlıya geçecektir.
